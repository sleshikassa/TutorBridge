TUTORBRIDGE - UWTSD COMPUTING PEER SUPPORT WEBSITE
===================================================

HOW TO OPEN
1. Extract the TutorBridge folder from the ZIP file.
2. Open the folder.
3. Double-click index.html.
4. Use the navigation menu to visit the five pages.

FILES
- index.html       Home page
- tutors.html      Example peer tutor directory
- resources.html   Free learning links grouped by module
- volunteer.html   Volunteer information and demonstration form
- contact.html     About and contact information
- css/style.css    Shared responsive stylesheet
- images/          Local SVG illustration placeholders

IMPORTANT
- This is a static HTML/CSS assignment prototype.
- Tutor profiles are fictional examples, not real or verified people.
- The volunteer form is a visual demonstration and does not store or send data.
- External learning links require an internet connection.
- Local pages and SVG illustrations work offline.
- Replace or supplement the SVG illustrations with suitable photographs later if desired.

MODULE INCLUDED

Introduction to Web and Database Concepts
- HTML and website structure
- CSS and website styling
- Basic database concepts
